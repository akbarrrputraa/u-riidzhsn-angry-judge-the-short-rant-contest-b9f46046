A program that writes one short, funny rant about an everyday annoyance: a smoke alarm that has never once warned its owner about smoke, because it saves its one low-battery beep for 3 a.m. — and it knows his address.

## Run it

```sh
python3 main.py
```

This writes the rant to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Python standard library only, no network, no randomness — two runs produce byte-identical output.
